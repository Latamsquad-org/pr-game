Logos y presentación de clanes
==============================

IMPORTANTE: no uses logos negros sobre fondo negro (no se ven).
Preferí PNG/SVG con color naranja (#ff8000) o blanco.

TODO se edita en un solo archivo:
  includes/clans_info.php

Ejemplo:
  'KKCK' => [
      'logo' => 'kkck.png',
      'blurb' => 'Comunidad competitiva de Project Reality.',
      'discord' => 'https://discord.gg/xxxx',
  ],

1) Logo por defecto (clanes sin imagen propia):
   Reemplazá:
   assets/img/clans/default.png
   (también default.jpg / default.svg)

2) Logo de un clan concreto:
   A) Subí: assets/img/clans/{slug}.png
      Ej. clan "LATAM SQUAD" → latam-squad.png

   B) O definí 'logo' en includes/clans_info.php

3) Texto de presentación (clans.php):
   Definí 'blurb' en includes/clans_info.php
   Si falta → se muestra "Clan {nombre}"

4) Discord del clan (botón bajo el contador de jugadores):
   Definí 'discord' => 'https://discord.gg/xxxx'
   Si falta o está vacío → no se muestra el botón

Formatos de logo: png, jpg, jpeg, webp, svg, gif.
